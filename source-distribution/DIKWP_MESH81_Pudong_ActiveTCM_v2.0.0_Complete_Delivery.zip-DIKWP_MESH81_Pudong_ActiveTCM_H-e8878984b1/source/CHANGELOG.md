# Changelog

## 2.0.0 — 2026-08

### Added

- Independent MESH8.1 hospital integration gateway and operations console.
- FHIR R4 facade, HL7 v2/MLLP, CDA R2, DICOMweb, REST/Webhook and secure flat-file adapters.
- Conservative MPI, consent records, signature envelopes, reliable outbox, retries and dead-letter queue.
- Human-reviewed core staging bridge and explicit prohibition of autonomous diagnosis, prescription and order submission.
- D/I/K/W/P semantic passports, versioned mappings, residual ledgers and append-only audit chain.
- OpenAPI contract, sandbox examples, deployment templates, backup/restore tools and comprehensive Chinese documentation.

### Preserved

- Original 28 advantage-disease workflow containers, 5 local extension packs and clinician-in-the-loop clinical workflow core.

### Boundary

This release is a synthetic engineering reference implementation. It is not a hospital-commissioned or hospital-accepted production system and contains no real patient data, credentials, certificates or vendor-private endpoint parameters.
