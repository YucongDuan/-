# 现场实施输入清单

在连接真实医院系统前，院方/厂商需提供并书面确认：

- 系统名称、厂商、版本、环境和责任人；
- 接口文档、WSDL/OpenAPI/字段字典、HL7 profile、FHIR profile、DICOMweb 能力；
- 测试端点、DNS、IP、端口、网络方向、防火墙、代理和时间同步；
- 认证方式、测试账号、客户端证书、CA 链、令牌范围和轮换流程；
- 患者号、就诊号、申请号、报告号、机构/科室/人员代码等标识域；
- 本地代码集、单位、字符集、时区、空值和更正/撤销规则；
- 业务触发、消息顺序、幂等、ACK、超时、重试、峰值和保留期限；
- 同意、数据用途、科研访问、脱敏、日志、审计和事件响应要求；
- 电子签名、处方、医嘱、号源、床位等高影响业务的权威系统和责任链；
- SIT/UAT 数据、验收用例、上线窗口、值守、回滚和变更审批。

缺少上述输入时，系统只能保持沙箱、只读或暂存模式，不应宣称完成生产对接。
