# 角色权限矩阵参考

下表是技术参考，最终以医院 IAM/RBAC 审批为准。

| 角色 | 主要读取 | 主要写入 | 明确禁止 |
|---|---|---|---|
| system_admin | 配置、健康、审计、用户映射 | 系统配置、连接器启停 | 以管理员身份形成临床结论 |
| integration_admin | 消息、队列、映射、连接器 | 重试、死信、技术暂存 | 直接批准诊断/处方/医嘱 |
| mpi_steward | 掩码患者标识、候选证据 | 链接、拒绝、解除 | 查看无关临床详情 |
| tcm_clinician | 职责范围病例与来源 | 临床观察、路径、方案、暂存批准 | 修改接口审计、绕过签名 |
| nurse | 护理/随访范围 | 观察、任务、打卡、职责内批准 | 临床限定诊断/处方 |
| rehab | 康复范围 | 目标、任务、随访 | 药物/诊断写入 |
| quality | 病例、来源、审计 | 复核意见、事件标记 | 代替临床人员签署 |
| research | 经批准去标识数据 | 无或受控标注 | 身份、原始审计、生产写回 |
| security_auditor | 安全/审计元数据 | 审计核验与事件记录 | 临床内容修改 |
| patient_proxy | 患者可见信息 | 意图、患者可填观察、打卡 | 接口、他人病例、高影响批准 |

建议采用职责分离：连接器配置者不能单独批准高影响临床写回；MPI 链接与临床批准分离；电子签名由外部权威平台验证。
