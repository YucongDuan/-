# 测试验收与上线清单

## 1. 验收层级

| 层级 | 验证内容 | 不能替代 |
|---|---|---|
| 单元/静态 | 解析、映射、权限、审计、边界 | 真实厂商互操作 |
| 合成端到端 | API、队列、MPI、暂存、恢复 | 真实患者/临床验证 |
| SIT | 医院测试环境接口与故障 | 业务接受 |
| UAT | 医护/运维流程和人因 | 监管/临床试验 |
| 安全测试 | 配置、身份、传输、漏洞 | 持续安全运营 |
| 试运行 | 限定范围真实运行 | 全院上线结论 |

## 2. 必测协议用例

### FHIR

- CapabilityStatement；
- 单资源创建/更新/查询；
- Batch/transaction Bundle；
- 条件/业务标识；
- 缺失必填、未知资源、超大载荷；
- 重复、版本冲突、未授权；
- OperationOutcome/错误结构。

### HL7 v2

- ADT A01/A03/A08；
- ORU 最终/更正/撤销；
- ORM/OML、SIU、MDM；
- ACK AA/AE/AR；
- 重复控制号、乱序、字符集、转义、多 OBX；
- 无 PID、错误版本、超长消息、非允许发送应用。

### CDA

- 正常文档；
- 缺患者/作者/时间；
- 未知章节；
- 外部实体/DOCTYPE 攻击；
- 文档摘要与签名状态。

### DICOMweb

- QIDO 条件查询；
- WADO 元数据/实例权限；
- 无权患者/研究；
- 超大对象；
- STOW 默认拒绝及审批后测试。

## 3. 可靠性用例

- 同一消息重复 10 次只形成一次业务动作；
- 对方 5xx/超时进入指数退避；
- 达到上限进入死信；
- 修复后重放保留原始审计；
- 进程中断后租约过期可恢复；
- 对方已执行但响应丢失时不盲目重复；
- 队列恢复不破坏顺序要求。

## 4. MPI 用例

- 权威患者号精确命中；
- 同名不同生日不合并；
- 同电话不同患者进入候选；
- 多院区标识域；
- 标识更改/作废；
- 人工链接、拒绝、解除；
- 错误链接影响评估；
- 页面和日志掩码。

## 5. 权限与安全用例

- 直接伪造可信代理头被拒绝；
- 过期/篡改令牌被拒绝；
- 不同角色访问矩阵；
- 无同意/用途不符被阻止；
- HMAC 重放 nonce；
- 请求大小限制；
- 路径穿越、注入、XML 外部实体；
- TLS/mTLS、证书到期、吊销；
- 日志不含明文 PHI；
- 审计链篡改被检测。

## 6. 临床安全用例

- 外部“诊断/处方/医嘱”不能直接写入；
- 临床暂存必须人工审核；
- 患者不确定时阻止高影响动作；
- 单位/代码未知时保留残差；
- 转诊目录不显示为实时号源；
- 趋势不自动改变治疗；
- 急诊信息明确提示使用医院急诊流程；
- 角色标签不能替代资质。

## 7. 上线前清单

- [ ] 真实接口清单和映射完成业务/技术双签；
- [ ] 测试数据不含未授权真实患者；
- [ ] 身份、角色、科室和职责分离确认；
- [ ] TLS/mTLS、证书、密钥轮换和网络策略完成；
- [ ] 演示令牌和默认秘密全部禁用；
- [ ] 高影响写回默认关闭；
- [ ] 备份、恢复和容灾演练通过；
- [ ] 性能、容量、故障、重复、乱序测试通过；
- [ ] 审计、日志、SIEM 和告警接入；
- [ ] 安全扫描/渗透测试问题闭环；
- [ ] 临床、护理、康复、质量、信息和运维培训完成；
- [ ] 试运行范围、值守、回滚和事件响应批准；
- [ ] 供应商和院方责任边界书面确认；
- [ ] 数据用途、保留、撤回和科研访问审批完成。

## 8. 上线后 7/30/90 天

7 天每日复盘消息失败、MPI 未决和人工暂存；30 天评估稳定性、用户负担、映射残差和安全告警；90 天决定维持、扩大、修改或回退。扩大范围必须有证据，不以“系统已运行”作为自动批准理由。
