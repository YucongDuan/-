# 数据字典与字段映射指南

## 1. 规范信封

每条消息建议包含：`envelope_id`、`source_system`、`source_message_id`、`protocol`、`message_type`、`occurred_at`、`received_at`、`patient_resolution`、`resources`、`raw_digest`、`mapping_profile/version`、`semantic_passport`、`residuals`、`purpose`、`status`。

## 2. 核心标识

- 患者标识：值 + 分配机构/域 + 类型 + 生效状态；
- 就诊标识：就诊号 + 患者引用 + 机构 + 时间；
- 申请/报告：申请号、报告号、版本、状态；
- 消息：发送方、设施、控制号/事件 ID；
- 资源：资源类型、ID、版本、业务标识；
- 审计：请求 ID、主体、动作、对象和前后摘要。

只有“值”没有“域”的患者号不能安全跨系统使用。

## 3. 时间

保存原始时间、解析后的带时区时间、来源时区和精度。不要把仅有日期的出生日期伪造成精确时间，也不要静默把本地时间当 UTC。

## 4. 代码和单位

每个代码保存系统、代码、显示、版本和原始值。未知本地码进入残差/待映射，不映射为“最接近”的标准码。数值结果同时保存值、单位、参考范围和异常标志。

## 5. 空值和否定

区分未提供、未知、不适用、明确无、被拒绝、被删除和解析失败。不能用空字符串压缩所有情况。

## 6. 映射版本

映射文件应使用语义版本或院方版本号。每条转换保存所用版本。版本升级后不要重写历史转换；需要重处理时生成新的转换记录并关联来源。

## 7. 往返与残差

往返测试不是要求两个系统完全相同，而是确认声明保持的字段可返回，声明不同的字段和不可表达信息可见。丢失字段、单位变化、代码降级、顺序变化和文本截断均应成为残差。

## 8. 脱敏

界面和日志默认掩码姓名、证件、电话和地址。测试集优先使用合成数据。科研导出应按批准方案去标识，并评估小样本、罕见病、时间轨迹和自由文本的重识别风险。
