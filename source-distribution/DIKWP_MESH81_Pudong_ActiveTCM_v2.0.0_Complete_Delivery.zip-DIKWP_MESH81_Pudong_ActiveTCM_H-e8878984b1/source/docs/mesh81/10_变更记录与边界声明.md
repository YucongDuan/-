# 变更记录与边界声明

## v2.0.0

- 新增独立院内集成网关和控制台；
- 新增 FHIR R4 双向门面、HL7 v2/MLLP、CDA、DICOMweb、REST/Webhook、文件交换；
- 新增患者主索引、同意、签名信封、可靠队列、死信、连接器健康；
- 新增临床暂存与人工审核桥接；
- 新增 MESH8.1 五元语义护照和映射残差；
- 新增 OpenAPI、配置模板、联调样例、部署和验收文档；
- 保留原 v1.0.0 临床工作流内核和安全边界。

## 明确边界

本发行版不是浦东新区中医医院正式委托、采购、验收或上线系统；未连接真实 HIS、EMR、LIS、PACS、统一身份、电子签名、号源、床位、药房或院内网络；不含真实患者数据、真实账号、证书或厂商参数；自动化测试不等于临床、生产、安全认证或监管批准。

系统不自动诊断、开方、确定剂量、选择穴位、提交医嘱或处理急诊；不替代持证人员、患者主数据、医院电子签名、医疗质量、数据治理和事件响应制度。

任何现场部署必须在合法授权、最小必要、临床人员在环、可审计、可撤销和可恢复的条件下进行。
